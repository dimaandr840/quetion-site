# Импорт 100 вопросов Java Developer

Набор находится в `scripts/data/java-interview.mjs` и состоит из четырёх частей по 25 вопросов. Каждый вопрос содержит подробный ответ, ключевые тезисы, уровень, категорию, теги и ссылку на веб-источник.

## Проверка без изменения базы

```bash
node scripts/import-questions.mjs data/java-interview.mjs --dry
```

Ожидаемый результат: `100` вопросов и `100` уникальных записей.

## Импорт через локальный API

1. Запустите приложение:

```bash
docker compose up -d --build
```

2. Выполните импорт:

```bash
node scripts/import-questions.mjs data/java-interview.mjs
```

По умолчанию импортёр обращается к `http://localhost/api`. Для другого окружения задайте адрес:

```bash
DEVPREP_API=https://qareerquest.com/api node scripts/import-questions.mjs data/java-interview.mjs
```

Импортёр создаёт отсутствующие категории, пропускает вопросы с уже существующим заголовком и выводит число созданных, пропущенных и ошибочных записей. Поэтому пакет можно безопасно запускать повторно.

## Почему это не SQL-миграция

В проекте уже есть штатный `scripts/import-questions.mjs`, который использует административный API, соблюдает текущую схему секций и создаёт категории. Такой пакет меньше связан со схемой PostgreSQL, чем SQL-миграция, и подходит для локального, тестового и production-окружения.
